# AutoMechanic — адаптивный прототип

Адаптивное веб-приложение на HTML/CSS/JavaScript для ноутбука и iPhone. Не требует сборки и платных библиотек.

## Что работает
- Форма автомобиля: марка, модель, год, версия и VIN.
- VIN lookup через официальный бесплатный NHTSA vPIC API.
- Поиск ремонтных руководств и иллюстраций во внешнем поиске по выбранному автомобилю и детали.
- Отдельные предупреждения: результаты поиска не являются подтверждёнными заводскими процедурами.
- Выбор локального PDF/изображения (файл не загружается и не сохраняется сервером).
- Адаптивный интерфейс, базовый manifest для добавления на домашний экран.

## Запуск локально
Для использования `fetch` и установки PWA лучше запускать через локальный HTTP-сервер, а не открывать `index.html` как `file://`.

Python 3:
```bash
cd AutoMechanic
python -m http.server 8080
```
Откройте `http://localhost:8080`.

На iPhone сайт должен быть доступен по HTTPS, чтобы установить его на экран «Домой». Для теста в одной Wi-Fi сети используйте IP ноутбука вместо localhost; для реального доступа нужен публичный хостинг и HTTPS.

## Публикация бесплатно
1. Создайте репозиторий GitHub и загрузите файлы из этой папки.
2. В настройках репозитория откройте **Settings → Pages**.
3. В разделе Build and deployment выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. Дождитесь публикации и откройте выданный HTTPS-адрес на ноутбуке и iPhone.
5. На iPhone в Safari нажмите **Поделиться → На экран «Домой»**.

Можно также опубликовать статические файлы на Cloudflare Pages или Netlify. Условия бесплатных тарифов могут меняться.

## Источники и границы достоверности
- NHTSA vPIC API: https://vpic.nhtsa.dot.gov/api/ — официальный API базовых данных VIN и автомобилей. Покрытие ориентировано на автомобили, представленные для рынка США; европейские версии могут не декодироваться полно.
- Описание vPIC: https://vpic.nhtsa.dot.gov/About
- FAQ vPIC: https://vpic.nhtsa.dot.gov/api/Home/Index/FAQ

vPIC не является базой пошаговых процедур ремонта. Поиск веб-страниц и изображений — это только переход к внешним результатам, не автоматическая верификация. Этот проект намеренно **не генерирует** расположение болтов, последовательность снятия или моменты затяжки без проверенного источника.

## Как подключать ремонтные данные в следующей версии
Для каждой инструкции храните:
- make/model/year/market/engine/trim и, если применимо, VIN-диапазон;
- название детали и операцию;
- последовательность действий и изображения;
- источник, URL/идентификатор документа, дату/версию и лицензию;
- ограничения применимости и предупреждения по безопасности;
- статус проверки редактором/механиком.

Не скрейпьте и не встраивайте платные руководства без разрешения. Даже если PDF доступен бесплатно для просмотра, это не обязательно разрешает копирование, перераспространение или коммерческое использование. Добавьте импорт лицензированных материалов через серверный интерфейс, контроль доступа, журнал загрузок и разграничение прав. Не публикуйте пользовательские PDF публично по умолчанию.

- Сделать серверное хранилище и авторизацию для мастерской.
- Добавить редактор источников, статусы проверки, резервное копирование и журнал изменений.
- Не показывать неподтверждённые схемы как инструкции.

## Текущий статус
Это работающий **прототип интерфейса**, а не полноценная универсальная ремонтная база. Точные схемы разборки для всех марок невозможно достоверно заполнить только бесплатным VIN API.
